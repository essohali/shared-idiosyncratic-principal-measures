# Shared and idiosyncratic principal measures for pultivariate point processes

Reproducibility repository for the manuscript **“Shared and idiosyncratic principal measures for multivariate point processes”** by Essoham Ali.

The repository reproduces the numerical study (Section 7), the Allen Brain Observatory Neuropixels application (Section 8), and the numerical results reported in the Supporting Information (Tables S1–S5).

## Repository structure

```text
simulation/                 Monte Carlo design, estimation, metrics, figures, robustness
application/                Allen preprocessing (Python), frozen derived data, R analysis
supporting_information/     Scripts and generated Tables S1–S5
results/application/        Allen tables and figures generated by the R pipeline
run_all.R                   Full reproduction pipeline
```

The simulation and Allen application retain separate estimator implementations because the final simulation code is specialized to `q=3`, whereas the Allen application requires the q-general implementation for `q=5`. Both implement the estimator described in the manuscript; keeping the exact versions used for each analysis avoids changing published numerical results.

## Quick start

Clone the repository and enter its root directory:

```bash
git clone https://github.com/essohali/shared-idiosyncratic-principal-measures.git
cd shared-idiosyncratic-principal-measures
```

For a complete reproduction of **Main + Supporting Information**:

```bash
Rscript run_all.R --workers 8
```

Change `8` to the number of parallel workers appropriate for your machine. The final Monte Carlo study is computationally intensive because it uses 500 replications for each of 12 main configurations, plus the robustness experiments.

## 1. Numerical study — Section 7

Run the final Monte Carlo experiment:

```bash
Rscript simulation/scripts/run_main.R --final --workers 8
```

The final design uses:
- `q = 3` components;
- `n = 100, 250, 500, 1000`;
- weak, balanced, and strong shared-dependence regimes;
- `B = 500` Monte Carlo replications per configuration;
- `delta = 0.05`, `tau_bar = 1000`;
- a 401-point estimation grid and 4001-point reference grid.

Main summaries are written to `simulation/results/summaries/`, while regenerable raw RDS objects are written to `simulation/results/raw/` and ignored by Git.

Generate the simulation figures:

```bash
Rscript simulation/scripts/make_figures.R
```

Figures are written to `simulation/figures/`.

### Robustness experiments — Section 7.3

Run both robustness experiments:

```bash
Rscript simulation/scripts/run_robustness.R --workers 8
```

This reproduces:
1. sensitivity to `delta in {0.02, 0.05, 0.10}` in the weak regime (`n=100`, `B=500`);
2. controlled departure from proportional cross-covariance with `gamma in {0, 0.10, 0.25, 0.50}` in the balanced regime (`n=500`, `B=500`).

Outputs are written to `simulation/results/robustness/`.

## 2. Allen Neuropixels application — Section 8

The frozen derived dataset is in `application/data/` and contains:
- 75 repeated stimulus presentations;
- 200 selected units (40 per cortical area);
- five areas: VISp, VISl, VISrl, VISal, VISam;
- stimulus-aligned spike events on `[0,2]` seconds.

The fixed stimulus condition is:
- orientation = 0 degrees;
- contrast = 0.8;
- temporal frequency = 2 Hz;
- spatial frequency = 0.04 cycles/degree.

Run the complete statistical application:

```bash
Rscript application/R/run_application.R
```

This produces the pooled 75-trial fit, proportionality diagnostics, shared/idiosyncratic variance decomposition, principal measures, temporal localisation summaries, publication figures, and separate fits for acquisition blocks 5 and 6.

Outputs are written to:

```text
results/application/tables/
results/application/figures/
```

The combined temporal figure used for the manuscript is generated as:

```text
results/application/figures/Figure_temporal_decomposition.pdf
```

### Optional: rebuild the derived Allen dataset from DANDI

The original data are publicly available from DANDI, Dandiset 000022, published version `0.251116.2247`, session `794812542`.

```bash
python application/python/stream_allen_to_excel_final_corrected.py
```

The script streams the remote NWB asset rather than downloading the full NWB file. The original NWB data are not redistributed in this repository.

## 3. Supporting Information

After the main simulation and Allen application have been run, generate the Supporting Information tables with:

```bash
Rscript supporting_information/make_SI_results.R
```

The script writes:

```text
supporting_information/results/
  Table_S1_idiosyncratic_operator_errors.csv
  Table_S2_idiosyncratic_spectral_PM_errors.csv
  Table_S3_idiosyncratic_loglog_slopes.csv
  Table_S4_scaled_shared_errors.csv
  Table_S5_Allen_block_sensitivity.csv
```

Tables S1–S4 are computed from the same main Monte Carlo replications used in Section 7. Table S5 is assembled from the pooled and block-specific Allen fits.

## Reproducibility notes

Random seeds are fixed in the simulation and application code. The robustness code uses common random numbers where appropriate. Each main workflow records `sessionInfo()` in its results directory. Generated large raw Monte Carlo `.rds` files are excluded from Git because they can be regenerated from the scripts and fixed seeds.
